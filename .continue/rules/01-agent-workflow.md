# Режим работы с проектом

- Когда пользователь просит создать, исправить, настроить или реализовать изменение,
  используй инструменты Agent mode (`read_file`, `edit_existing_file`,
  `create_new_file` и при необходимости `run_terminal_command`) и внеси изменение в
  рабочую папку. Не ограничивайся ответом с примером кода.
- Сначала прочитай связанные файлы и соблюдай существующую архитектуру проекта.
- После редактирования выполни подходящие тесты или проверки и сообщи результат.
- Работай только внутри открытой рабочей папки, если пользователь явно не указал иное.
- Не удаляй данные и не выполняй необратимые команды без отдельного подтверждения.
